# Free SFX Download – category packs

This branch only holds the category ZIP packs for https://mydevspace2.github.io/free-sfx-download/ (kept off the Pages branch so the website stays small).
Each ZIP contains every sound of one category as MP3 (320 kbps) and WAV (48 kHz / 24-bit) plus LICENSE.txt.
All sounds are CC0 1.0 / public domain. Original sources, authors and licences: SOURCES.md on the main branch.
The ZIPs are rebuilt by `_source/build.py` (main branch) into `release_zips/` and committed here.
