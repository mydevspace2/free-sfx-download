About these UI & click sound effects

Clicks make screen recordings, tutorials and app promos feel tactile. This set mixes real mouse and trackpad clicks with clean interface sounds: button clicks, select ticks, toggles, switch on/off and window open/close sounds.

Use the real mouse clicks in software tutorials where the cursor clicks on screen, and the cleaner interface sounds for motion-graphic buttons, menus and app mock-ups. They are also useful in games and websites, since every file is CC0.

A click sound effect makes a screen recording easier to follow, because viewers hear exactly when the cursor presses something. Use the real mouse click, double-click and trackpad click in software tutorials, and the clean interface sounds (switch on and off, toggle, window open and close, button click) for app promos, website mock-ups and animated UI. Keep clicks quiet in the mix; they should feel tactile rather than draw attention to themselves.
