# SOURCES – every sound, its original, author and licence

All sounds are CC0 1.0 / public domain. Fetched 2026-11-15 (34 Cartoon & Funny additions from BigSoundBank on 2026-11-16). Processing: leading silence trimmed, 3 ms fade-in + short fade-out (0.4 s where a long file was shortened), loudness levelled towards -14 LUFS with true peak <= -1 dBTP (very short transients stay peak-limited, so they measure below -14 LUFS), exported as MP3 320 kbps and WAV 48 kHz/24-bit.
